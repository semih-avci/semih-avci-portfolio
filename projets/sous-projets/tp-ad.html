Active Directory & Server.

Administration Windows Server / Gestion des Identités / GPO

1. Contexte du Projet

Ce projet simule le déploiement du cœur informatique d'une entreprise. Mon rôle a été de mettre en place un contrôleur de domaine sous Windows Server pour centraliser la gestion des utilisateurs et sécuriser les postes de travail. J'ai configuré un domaine DNS local (Avci.local) et assuré l'interconnexion entre le serveur et des clients Windows 10, créant ainsi un environnement de production standardisé.

2. Travail Fourni

A. Infrastructure & Contrôleur de Domaine

J'ai commencé par l'installation du rôle AD DS (Active Directory Domain Services) sur le serveur. J'ai promu la machine en tant que contrôleur de domaine et configuré les services DNS indispensables à la résolution de noms. J'ai ensuite procédé à la jonction des postes clients au domaine, validant ainsi la communication entre les différentes couches de l'infrastructure. 


# Vérification du statut du domaine via PowerShell
PS C:\> Get-ADDomainController -Filter * | Select-Object Name, IPv4Address, IsGlobalCatalog

Name            IPv4Address     IsGlobalCatalog
----            -----------     ---------------
SRV-AVCI-DC01   192.168.10.5    True

B. Annuaire & Centralisation des Données

J'ai structuré l'annuaire en créant des Unités d'Organisation (OU) pour refléter les départements de l'entreprise. Pour chaque collaborateur, j'ai mis en place un Mapping Réseau automatique. Ce système permet à l'utilisateur de retrouver ses fichiers personnels directement sur le serveur (via le lecteur Z:) depuis n'importe quel poste du domaine. 


# Exemple de logique de création d'arborescence (Powershell conceptuel)
PS C:\> New-ADOrganizationalUnit -Name "Direction" -Path "DC=Avci,DC=local"
PS C:\> New-ADUser -Name "Enzo Lamanna" -GivenName "Enzo" -Surname "Lamanna" `
                   -UserPrincipalName "elamanna@Avci.local" `
                   -Path "OU=Direction,DC=Avci,DC=local" `
                   -HomeDirectory "\\SRV-AVCI-DC01\Partage\elamanna" -HomeDrive "Z:"

C. Sécurisation par Stratégies (GPO)

Pour homogénéiser le parc et renforcer la sécurité, j'ai déployé plusieurs GPOs. J'ai notamment imposé un fond d'écran d'entreprise, restreint l'accès au Panneau de Configuration et à l'Invite de Commande pour les utilisateurs standards. J'ai aussi instauré une bannière légale d'avertissement à l'ouverture de session pour respecter les normes de conformité.

3. Difficultés Rencontrées

Le défi majeur a été la résolution DNS lors de la jonction au domaine. Un mauvais pointage empêchait le client de trouver le contrôleur de domaine ; j'ai dû corriger la configuration IP statique. J'ai également géré des conflits de permissions NTFS sur les dossiers partagés, nécessitant une analyse fine pour permettre le mapping réseau tout en protégeant l'intégrité des données des autres utilisateurs.

4. Résultat Final

L'infrastructure est pleinement opérationnelle : un utilisateur peut se connecter sur n'importe quelle station de travail avec ses identifiants uniques, retrouver ses documents synchronisés et se voir appliquer les restrictions de sécurité définies. Cette expérience a consolidé ma maîtrise de l'écosystème Windows Server, compétence indispensable pour l'administration d'un parc informatique d'entreprise.
