## Presentation commune

Les dix pages des onglets et du parcours Fortinet utilisent `themes/navigation.css`
pour la navigation, les en-tetes, les largeurs, les espacements et les finitions.
Le menu responsive et son accessibilite sont geres par `scripts/navigation.js`.
Les autres feuilles de style ne doivent pas redefinir ces regles communes.
La presentation noir et dore existante reste la reference, sans nouvelle refonte.
